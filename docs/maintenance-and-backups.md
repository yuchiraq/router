# Router by Qoncept: обслуживание и резервные копии

## Автоматическое обслуживание

Каждый добавленный HTTP(S)-сервис проверяется при запуске и затем с паузой 10 секунд между циклами. Одновременно выполняется не более восьми проверок, тайм-аут одной проверки составляет 3 секунды. Проверяется адрес, указанный в маршруте. Ответы 5xx и ошибки соединения считаются сбоями; редиректы, 401, 403 и 404 означают, что HTTP-сервер отвечает. Это проверка доступности, а не полноценная диагностика базы данных или внутренних функций сайта.

Две последовательные неудачные проверки включают автоматическое обслуживание. Ошибка соединения при обычном запросе включает его сразу. Две успешные проверки снимают автоматическое обслуживание. Ручное и глобальное обслуживание сохраняются до отключения администратором; панель управления исключена из блокировки.

Заглушка возвращает HTTP 503, `Retry-After: 15` и `Cache-Control: no-store`. Для API и изменяющих запросов используется JSON, а не HTML. Исходные POST-запросы не повторяются. Страница проверяет восстановление каждые 15 секунд и показывает кнопку возврата, сохраняя партию в 2048. Все ресурсы заглушки находятся локально; публично доступен только фиксированный список файлов, без доступа к настройкам панели.

## Telegram

В разделе «Уведомления» появилось событие «Сайт недоступен: включён сервисный режим». При миграции старых настроек оно включается, если раньше не было задано. Явно выключенная настройка сохраняется. Общая отправка, токен, получатели и тихие часы продолжают применяться.

Сообщение содержит домен, причину сбоя, время с часовым поясом и факт автоматического включения обслуживания. Событие формируется один раз при переходе в недоступное состояние, в том числе при одновременных запросах. После восстановления новый сбой может породить новое сообщение. Ручная/глобальная пауза и адрес панели не создают уведомлений об автоматическом обслуживании.

Отправка выполняется отдельно от обработки HTTP-запроса. Используется существующий механизм Telegram; ошибки доставки пишутся в журнал без токена. Постоянной очереди и доставки после тихих часов нет. Состояние доступности хранится в памяти: после перезапуска длительный сбой будет обнаружен заново и может вызвать новое уведомление.

## Резервные копии

На странице доступны сводка, вкладки «Задания» и «Архивы», поиск, фильтр архивов по заданию и ручное обновление. Кнопка запуска в строке создаёт копию по сохранённым настройкам. Редактор открывается в диалоге; несохранённые изменения защищены подтверждением закрытия, при ошибке сохранения поля остаются заполненными.

Удаление задания по существующей серверной логике удаляет также его архивы. Подтверждение явно предупреждает об этом и показывает количество. Исходные файлы не удаляются. Это поведение не является удалением только расписания.
